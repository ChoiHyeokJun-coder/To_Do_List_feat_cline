# Microsoft To Do 스타일 할 일 관리 앱

Vite + React + Tailwind CSS로 만든 Microsoft To Do 스타일의 할 일 관리 애플리케이션입니다.

## 🎯 주요 기능

### 📝 할 일 관리
- ✅ 할 일 추가/수정/삭제/완료
- ✅ 할 일 제목 더블클릭으로 인라인 수정
- ✅ 동그란 체크박스로 완료/미완료 토글
- ✅ 완료된 할 일에 취소선 표시

### 📋 세부 단계 (Sub-tasks)
- ✅ 세부 단계 추가/완료/삭제
- ✅ 모든 세부 단계 완료 시 할 일 자동 완료
- ✅ 세부 단계 전체 완료/삭제 버튼
- ✅ 세부 단계 진행률 표시

### 📅 일정 관리
- ✅ 마감일 설정 기능
- ✅ "나의 하루" 기능 (오늘 마감일이거나 수동으로 추가한 항목 표시)
- ✅ "나의 하루"에 할 일 추가 토글

### 🎨 사용자 인터페이스
- ✅ Microsoft To Do 스타일 디자인 (화이트 배경 + 파란색 포인트)
- ✅ 다크 모드 지원 (밝은 회색 톤)
- ✅ 반응형 UI (모바일/태블릿/데스크탑)
- ✅ 부드러운 애니메이션 및 전환 효과

### 💾 데이터 관리
- ✅ LocalStorage 자동 저장 (새로고침해도 데이터 유지)
- ✅ 다크 모드 설정 저장

### 🔧 편의 기능
- ✅ 전체 할 일 완료/삭제 버튼
- ✅ 사이드바 메뉴 ("나의 하루", "전체 할 일")
- ✅ 상세 패널에서 모든 정보 관리

## 📱 반응형 디자인

### 모바일 (< 768px)
- 상단에 드롭다운 메뉴와 다크모드 토글
- 사이드바 숨김
- 상세 패널은 하단에서 올라오는 시트 형태 (최대 높이 80%)

### 태블릿 (768px ~ 1024px)
- 사이드바 표시
- 상세 패널은 하단 시트 형태

### 데스크탑 (> 1024px)
- 사이드바 + 할 일 목록 + 상세 패널 3단 레이아웃
- 모든 기능을 한 화면에서 확인 가능

## 🚀 시작하기

## 💡 개발 과정 (프롬프트 로그)

### 1. 초기 프로젝트 설정
```
너는 지금부터 유능한 프론트엔드 개발자야. 현재 열려있는 폴더에 Vite, React, Tailwind CSS를 사용해서 새로운 프로젝트를 초기화(install)하고, Microsoft To Do 스타일의 할 일 관리 앱을 만들어줘.
```

### 2. UI 및 기본 기능 구현
```
화면 왼쪽에는 사이드바가 있고 '나의 하루', '전체 할 일' 메뉴가 있어야 해.
메인 화면에서는 할 일을 입력하고 추가하는 텍스트 인풋과 버튼이 있어야 해.
할 일 목록 옆에는 동그란 체크박스가 있어서 누르면 완료선(취소선)이 그어지게 해.
전체적인 색상은 깔끔한 화이트 배경에 마이크로소프트 특유의 파란색(Blue) 포인트 컬러를 사용해줘.
```

### 3. 상세 기능 추가
```
특정 할 일을 클릭하면 오른쪽에 상세 패널이 열리고, 여기서 '세부 단계(Sub-tasks)' 추가, '마감일' 설정 기능을 구현해줘.
사이드바의 '나의 하루'를 클릭하면, 마감일이 오늘이거나 별도로 지정된 항목만 필터링해서 보여주는 로직을 작성해줘.
```

### 4. 버그 수정 및 개선
```
나의 하루에서 할일 목록이 추가되지 않는 문제가 있어
하단부분에 전체 완료, 전체 삭제 칸을 넣어주고 할일을 수정가능하게 만들어줘
```

### 5. 세부 단계 기능 개선
```
세부 단계를 체크할때 체크가 안되고 있고 세부단계에도 전체 완료와 같은 기능을 넣어줘
또한 다크모드도 설정할수 있게 만들어 줬으면 해
```

### 6. 다크모드 밝기 조정
```
세부단계에 체크박스를 누르면 완료는 되었다고 나오는데 체크가 되었다는 표시가 되지않아 이 기능을 추가해주고
다크모드가 너무 어두워서 조금만 밝게 만들어줘
```

### 7. 즉시 업데이트 기능
```
세부단계를 추가했을때 바로 표시되게 만들어줘
```

### 8. 고급 기능 추가
```
세부 단계를 추가했을때 전부 완료되면 할일이 자동적으로 완료되게 만들어줘

바이브코딩 입문자들도 쉽게 알수 있게 주석을 만들어주고
새로고침시에도 이전에 데이터가 그대로 남아있게 Local Storage에 저장할수 있게 만들어주고
반응형 UI를 만들때 모바일 UI, 데스크탑 UI, 패드 UI를 구분해서 만들어
```

### 9. 모바일 UX 개선
```
모바일용 UI로 될때는 세부정보가 하단부분에 뜨게 만들어서 할일목록이 가려지지 않게 해줘
```

## 🔍 주요 함수 설명

### `addTodo(title)`
새로운 할 일을 추가합니다. "나의 하루" 뷰에서 추가하면 자동으로 `isMyDay: true`로 설정됩니다.

### `toggleSubtask(todoId, subtaskId)`
세부 단계를 체크/해제합니다. 모든 세부 단계가 완료되면 할 일도 자동으로 완료 처리됩니다.

### `getFilteredTodos()`
현재 보기 모드에 따라 할 일 목록을 필터링합니다.
- `'all'`: 모든 할 일 반환
- `'myday'`: 오늘 마감일이거나 `isMyDay: true`인 항목만 반환
